# Data Analytics Portfolio

Welcome to my data analytics and machine learning portfolio. This repository contains hands-on projects demonstrating data preparation, exploratory analysis, statistical thinking, and predictive or unsupervised modeling.

## Featured projects

### Automobile Segmentation with Hierarchical Clustering
An unsupervised learning project that groups 32 automobile models using 11 vehicle characteristics. It compares Average and Ward linkage, evaluates cluster counts with silhouette scores, profiles the segments, and visualizes the results with PCA.

- [Open project overview and instructions](projects/automobile-hierarchical-clustering/README.md)
